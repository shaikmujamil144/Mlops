# CLA 4 — Titanic ML Model Deployment and FastAPI Serving

Beginner-friendly implementation of the six tasks in the assignment.

## Dataset (required)
Use **only** the Titanic competition `train.csv` from Kaggle:
https://www.kaggle.com/competitions/titanic/data

1. Sign in to Kaggle and download `train.csv` from the Data tab.
2. Put the file at `data/train.csv`.
3. Do not use `test.csv` as the labelled training dataset; it has no `Survived` label.

The dataset is not bundled because it must be obtained from the specified Kaggle source.

## Setup
Python 3.10 or newer is recommended.

```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
macOS/Linux:
```bash
source .venv/bin/activate
```

Install packages:
```bash
pip install -r requirements.txt
```

## Run tasks in order

### Task 1 — Train model
```bash
python train.py
```
The script performs an 80/20 stratified train/test split, fits preprocessing and Logistic Regression, prints test accuracy, saves the complete scikit-learn pipeline to `model.pkl`, and records the held-out test row indices in `outputs/test_row_indices.csv`. The model is trained once; all later scripts load this saved pipeline.

### Task 2 — Online inference (one record)
```bash
python online_inference.py
```
Shows one prediction for one passenger input.

### Task 3 — Batch inference (20 records)
```bash
python batch_inference.py
```
Writes `outputs/batch_predictions.csv` using 20 records from the test split saved by `train.py`. These records were not used to fit the model, so they are held out from training.

### Task 4 — Streaming inference (10 records)
```bash
python streaming_inference.py
```
Prints one held-out test prediction at a time with a one-second delay between records.

### Task 5 — FastAPI model serving
Start the server in one terminal:
```bash
uvicorn app:app --reload
```
Open Swagger UI: http://127.0.0.1:8000/docs

Test:
- `GET /health` — expected `{"status":"ok","model_loaded":true}` after training.
- `POST /predict` — use this valid JSON body:
```json
{
  "Pclass": 3,
  "Sex": "male",
  "Age": 22,
  "SibSp": 1,
  "Parch": 0,
  "Fare": 7.25,
  "Embarked": "S"
}
```
- Invalid request example: set `"Pclass": 5` or `"Sex": "other"`. Pydantic validation should return HTTP 422.
- Python client: in a second terminal, run `python client.py`.

## Files
- `train.py` — preprocessing, split, training, evaluation, model save
- `online_inference.py` — one record prediction
- `batch_inference.py` — 20 predictions and CSV export
- `streaming_inference.py` — 10 sequential predictions, 1-second delay
- `app.py` — `/health` and `/predict` API endpoints with Pydantic validation
- `client.py` — tests `/predict` using Python `requests`
- `model.pkl` — generated by `python train.py`
- `outputs/test_row_indices.csv` — held-out test rows saved by `python train.py`
- `outputs/batch_predictions.csv` — generated by `python batch_inference.py`
- `report.pdf` — assignment observations
- `screenshots/` — add screenshots of your actual local outputs and Swagger tests
